# UI Mockups

Static discussion prototype for the V1 DT Check-in frontend.

## Open It

Open [index.html](./index.html) in a browser.

## First-Pass Scope

- Tester: login, signup, inactive state, modules, submissions, form, detail
- Admin: dashboard, pending users, submissions, detail, no-submission-yet

## Notes

- No real auth, API calls, or state yet
- This is for layout and flow discussion only
- The prototype reflects the agreed v1 rule that completed submissions can
  still show a missing-file warning
