# Admin UI Mockup

Static discussion prototype for the ML Technologies DT Check-in admin console.

## Open It

Open `index.html` in a browser.

## Scope

- Dashboard
- Daily Submissions table
- Daily Submission detail with edit drawer
- Workorders table
- Workorder detail with edit drawer
- Users
- Pending Users
- No Submission Yet
- Reports / CSV export concept

## Notes

- This is a static prototype with sample data only.
- Admin web access is modeled for `ADMIN` users only.
- Drive testers appear as managed users and daily submission owners, but do not access this admin UI in v1.
- "No Submission Yet" means no daily submission record exists for the selected date.
- "File Pending" means a checked-out daily submission exists but has no active closeout file.
